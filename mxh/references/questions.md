# 思考题

识别题目要求的是概念解释、原因、意义、措施、比较还是材料分析。开头直接回答设问。措施题写清谁做什么、通过什么方式及解决什么问题。材料题逐项说明材料中的事实怎样体现对应原理。比较题先确定共同维度，再说明联系和区别。多问分别作答。

## 把原理用到材料上

每个主要论点找一项具体材料证据，再补一句推理，说明这个事实为什么支持判断。改稿时，圈出「体现了」「说明了」后面的结论，检查前文是否交代了具体的因果、条件或相互作用。题干限定原理时，优先用题干指定的原理。资料只支持局部判断时，限定结论的范围。

历史题引用纪念讲话或政府报道时，分别记录历史事件发生日、纪念活动日和文章发布日期。引用近年的政策作补充时，说明它是后续发展还是题目所属时期已有的依据。参考[上海建桥学院马原课程考核标准](https://mksxy.gench.edu.cn/2025/1016/c807a172584/page.htm)及[苏州市委统战部刊载的抗战纪念讲话](https://tzb.suzhou.gov.cn/tzb/tzdt/201407/51e3649b11664dc8a2984b86b25770c2.shtml)。

## 六门课的分析入口

| 课程 | 优先使用的分析线索 |
| --- | --- |
| 中国近现代史纲要（史纲、纲要） | 界定时期，按历史背景、事件、因果与影响展开，用史实支撑判断。 |
| 马克思主义基本原理（马原） | 准确定义原理，写明适用条件，把概念用于解释材料中的具体关系。 |
| 毛泽东思想和中国特色社会主义理论体系概论（毛概） | 先识别历史阶段及其要解决的问题，再解释理论形成的条件、内容与实践。 |
| 习近平新时代中国特色社会主义思想概论（习概） | 界定新时代议题，解释理论要求如何落实为制度安排和实践路径。 |
| 思想道德与法治（思法） | 区分道德评价和法律判断，从具体行为、价值冲突或权利义务分析。涉及现行法律时核对条文及适用条件。 |
| 形势与政策 | 先确定专题、时点和背景，再用经核对的事实与政策解释原因、影响或对策。 |

## 示例

题目「新时代如何巩固和发展爱国统一战线？」属于措施题。未给课程时，可以先按新时代统战专题答，交正式作业时以指定章节为准。

可先用一句话概括目标，再把措施组织为三个层次：

1. **坚持党的领导，完善统战工作格局。** 加强各方面工作的协调，把凝聚共识、汇聚力量落实到各领域的工作中。
2. **坚持大团结大联合，在共同目标下团结不同群体。** 处理好共同性与差异性的关系，发挥新型政党制度的作用，加强同民主党派和无党派人士的团结合作。
3. **按领域落实。** 根据篇幅说明如何促进民族团结、推进我国宗教中国化、联系党外知识分子和新的社会阶层人士、促进非公有制经济健康发展以及加强侨务工作。每个选用的例子说明具体做法如何服务于团结目标。

核对依据为[党的二十大报告](https://www.mod.gov.cn/gfbw/sy/tt_214026/4924360.html)第六部分第四节。这是示范提纲，引用或补充新政策时按原题重新核对。
