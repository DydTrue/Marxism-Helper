# MXH · 大学思政课写作助手

MXH 是面向大学生的 Agent Skill，帮助你回答课程思考题、起草或修改思想汇报，以及整理红色活动实践感悟。

覆盖《中国近现代史纲要》《马克思主义基本原理》《毛泽东思想和中国特色社会主义理论体系概论》《习近平新时代中国特色社会主义思想概论》《思想道德与法治》《形势与政策》。

## 安装

在装有 Node.js 和 npm 的电脑上，打开终端运行：

```sh
npx skills add DydTrue/Marxism-Helper --skill mxh --agent codex --global --copy
```

安装到 Claude Code 时，把 `--agent codex` 改成 `--agent claude-code`。只想在当前项目使用时，进入该项目后运行命令并省略 `--global`。

## 使用

在 Codex 中新开会话，输入 `$mxh`，再附上题目、老师的要求和相关材料。可以参考下面的提问方式。

- **思考题** ·「$mxh 这是习概课思考题：新时代如何巩固和发展爱国统一战线？约 500 字，请依据我附上的课件作答。」
- **思想汇报** ·「$mxh 请根据这段时间的学习笔记和真实经历，起草一份交给党支部的思想汇报。落款日期和格式见附件。」
- **实践感悟** ·「$mxh 请根据我的纪念馆参观笔记写一篇实践感悟，重点分析最有印象的那件展品与纲要课内容的联系。」

如果你使用普通聊天工具，可以上传 [SKILL.md](mxh/SKILL.md) 和当前任务对应的指南，然后请模型按指南处理。也可以直接粘贴这两份文件的内容。
